# Swarmie 0.1.1

**Pre-1.0 feature release.** The Adapter contract remains `0.1`; this release
adds backward-compatible state, observation, setpoint and SDK surface.

## Highlights

- Live self-state and persistent velocity setpoints.
- Nine-slot inventory snapshots and explicit single-block observation.
- Python SDK with exact-UUID selection, action handles, cancellation, events and
  epoch/gap-aware reconnect.
- A verified minimal farming-preparation workflow.
- `/swarmie help` plus a current Python/JSONL API quick reference.
- A test-only DCPU-16/MMIO bridge spike: guest MMIO → existing Runtime → Entity
  movement → terminal status/IRQ.
- Smaller white/cyan robot shell with four independently animated idle wings.
- Draft SDB v0 device-bus specification for future player-defined devices.

## Important status

- **Public stable surface:** the four legacy commands, `state`, `inventory`,
  `observe_block`, velocity setpoints and the localhost JSONL/Python SDK.
- **Experimental / internal:** DCPU/MMIO (test-only subset), the draft SDB
  specification (no implementation), and the legacy `LocalSensor` debug
  capability (not part of the Adapter contract or SDB API).
- **Still not available:** general farming, pathfinding, task scheduling,
  public region/entity/sensor observation, orientation setpoint, container GUI,
  DMA, NIC, or persistent DCPU programs.
